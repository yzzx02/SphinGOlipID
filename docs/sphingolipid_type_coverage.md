# 鞘脂类型核对

85,710 行旧清单只用于核对类型和名称；实际库以当前合法链组合为主，不按旧记录数扩库。

共保留 113 个旧类型名，其中 myriocin 单列为非鞘脂；105 个类型名对应当前正模式 MS2 可检索类别。

“可检索”表示存在该类型的碎片规则和合法库记录，不表示旧表每个链组合均已收录，也不是实测召回率。糖连接、立体构型、OH 或乙酰化位置不能仅凭别名确认。新补理论谱按总组成/分子种报告，不升级链组成。
