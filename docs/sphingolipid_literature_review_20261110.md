# 八类历史名称的文献复核与处理

本轮仅在 SphinGOlipID 独立分支实施。结论是 **1 类补入一个有标准谱证据的组成，
另 7 类不启用 MS2**；后者只留参考存档，不补齐旧网格，也不计作已支持类别。
原始 85,710 行 CSV、LipidGate 原始及分支库均不改。未重跑实测 benchmark，
下列验证不代表新召回率。

| 旧名称 | 本轮处理 | 文献依据与边界 |
| --- | --- | --- |
| 1-O-acetyl-Cer | 不加入 MS2 | [Lei 等](https://doi.org/10.3390/md19110585)证明了 1-O-acetyl-Cer 的存在，但 Fig. 5 的关键碎片来自 **EI-MS**；不能直接移作原生 ESI 规则。 |
| 1-O-acetyl-ω-linoleoyloxy-Cer | 不加入 MS2 | [双酯化 Cer 原始研究](https://doi.org/10.1007/s00216-019-02301-3)定义的是长链 **1-O-acyl**，不能当作旧名单字面的 C2 **acetyl**。 |
| 3-keto Cer | 不加入旧系列 MS2 | [Pilz 等](https://doi.org/10.1093/hmg/ddab309)有饱和 **3-ketodihydroCer（NdK）** 标准，C18 骨架有 m/z 270 特征；这不等于旧名单全部 3-ketoCer，尤其不饱和 NK 系列，已得到验证。本轮不把该通道外推到整个旧网格。 |
| LM1 | 核准名称与组成、修正参考分子式和质量；不启用独立 MS2 | LM1 是乳系列 IV³-α-Neu5Ac-Lc₄Cer；nLM1 是相应新乳系列，二者不能混为一个已确认结构。[命名与实验研究](https://doi.org/10.3390/ijms22168844)。 |
| N,N,N-trimethylSo | 参考离子形式修正为 **[M]+**；不加入 MS2 | [Ejsing 等](https://doi.org/10.1371/journal.pone.0144817)有未衍生化合成 trimethyl-C18-sphingosine 对照，主要 m/z 60.08；但仅一根常见胺离子不足以作为本次保守的独立骨架确认规则。 |
| N,N-dimethylSo | **仅加入 d18:1 的 [M+H]+ 参考** | [Zhu 等 Fig. 7b](https://doi.org/10.1038/nprot.2013.004)给出原生正模式 20/40 V 标准谱，并对照同分子式 SPB(d20:1)。采用 N 相关低质量片段组合，不能只凭共有失水峰。 |
| N-methylSo | 不加入 MS2 | 本次未建立有可靠原生正模式标准谱支撑的 N-单甲基专属门控；不把 N,N-二甲基碎片平移或仅据分子式补规则。 |
| ketoSo | 不加入 MS2 | [HMDB0245914](https://hmdb.ca/metabolites/HMDB0245914)可核对不饱和 3-ketosphingosine 的结构/分子式，所列 LC-MS/MS 为预测谱；不能替代未衍生化实测标准，也不能套饱和 ketoSa 的门控。 |

## LM1 修正

旧目录 `LM1(d34:1)` 的 **C60H110N2O23** 缺少一个 NeuAc 残基
（C11H17NO8）。按 LM1 的 **Hex3HexNAcNeuAc-Cer** 组成修正为
**C71H127N3O31**，同时重算 [M+H]+；`original_formula` 和
`reference_correction` 保留修正前数据与依据。该组成与 GM1 同分子式，
不意味着糖连接相同。原名 LM1 保留，不改名 nLM1、不直接映射 GM1；
这些参考仍不进入默认 MS2 候选。

## DMS 的分池与门控

唯一新增组成为 **N,N-dimethylSo(d18:1)**，中性式 **C20H41NO2**，
前体 **[M+H]+ 328.3210**。以下是对原文三位小数 m/z 的元素组成赋值，
使用质子/电子质量后计算的理论值；不是声称原文给出了这些精确式或精确强度。

| 池 | 名称或赋值 | 理论 m/z | 用途 |
| --- | --- | --- | --- |
| HG | C3H8N+ | 58.0651 | 可计入 HG 命中数 |
| HG | C5H10N+ | 84.0808 | 可计入 HG 命中数 |
| HG | C7H12N+ | 110.0964 | **必须命中** |
| Other | C6H10N+ | 96.0808 | 可选支持 |
| Other | [M+H−CH2O−H2O]+ | 280.2999 | 可选支持 |
| Other | [M+H−2H2O]+ | 292.2999 | 可选支持 |
| Other | [M+H−H2O]+ | 310.3104 | 可选支持 |
| Other | [M+H]+ | 328.3210 | 可选支持 |

沿用当前新增组成类的 **HG/Other＝60/40**、两 HG 时取最高强度的默认评分。
准入需要 **至少两根独立 HG 实测峰，并包含 110.0964**；只有共有失水峰、
只有 110，或只有 58+84 都不通过。Other 必须是原谱基峰 **严格 >0.5%**，
不单独门控；同一质心只计一次，保留原有饱和上限、总分和匹配数排名。
原有 1% 链确认接口与其他脂类规则不改。本条只报告单碱基组成，不确认双键
位置/构型或立体化学，不扩展 N-甲基化同系物网格。

MSP 中强度为理论参考值；未把图中未定量的柱高当作实测强度，未生成伪造谱图。

## 库与代码的可追溯性

在临时目标中增补并运行现有链限制整理；随后从 MSP 逐条重新归一化，
使用原共享过程生成羟基脂酰衍生记录。旧索引只提供稳定编号和全字段对照，
不复用旧归一化或检索计划。重建后逐条核对既有记录的全部科学字段、编号
和相对顺序；负模式仅因公共代码指纹变化而重建索引，负模式 MSP 与科学内容不改。
历史迁移清单 `config/engine_revision.json` 保留；本轮本地科学修订另立清单。
